## Workflow

### For Each Track:

1. **🎼 Locate Sheet Music**
   - Find PDF sheet music for the film theme
   - Save as `sheet_music.pdf` in the track directory
   - Sources:
     - Your existing collection
     - MuseScore community scores
     - Sheet music websites (legal purchases)
     - Film score anthologies

2. **📝 Create Performance Instructions (lyrics.md)**
   - Use the sheet music as reference
   - Write detailed performance notes like in `06-forrest-gump/lyrics.md`
   - Include:
     - Section markers: `[Intro]`, `[Main Theme]`, `[Variation]`, etc.
     - Mood descriptions: "notes hang suspended on the breeze"
     - Technical directions: tempo, dynamics, articulation
     - Signature elements: "cowbell", specific motifs
     - Spoken lines (if any)

3. **🎨 Define Style (style.md)**
   - Describe the musical style for this specific track
   - Reference the composer's approach
   - Include emotional tone and target feel
   - Example: See `06-forrest-gump/style.md`

4. **🎵 Generate with Suno**
   - Use `lyrics.md` + `style.md` to create Suno prompts
   - Generate tracks at: https://suno.com/@raremajorkey9311
   - Save Suno links in your track files

## Tips for Finding Sheet Music

### Free Sources:
- **MuseScore.com** - Search for "[film name] piano" or "[film name] theme"
- **IMSLP.org** - Public domain scores (older films)
- **8notes.com** - Free piano arrangements
- **PianoLetterNotes.com** - Simplified versions

### Paid Sources:
- **MusicNotes.com** - Official arrangements
- **SheetMusicPlus.com** - Wide selection
- **Hal Leonard** - Film score books

### Search Terms:
- "[Film] main theme piano sheet music PDF"
- "[Film] score Alan Silvestri PDF"
- "[Film] soundtrack piano arrangement"
